# 👥 Employees Database

A relational database project developed using **Microsoft SQL Server 2022** and **T-SQL** for managing employee information, departments, positions, salaries, and organizational operations. The project demonstrates database design, normalization, relationships, and SQL scripting for employee management.

---

## 📌 Features

- 👥 Employee Management
- 🏢 Department Management
- 💼 Position Management
- 💰 Salary Management
- 📈 Organizational Records
- 🔗 Relational Database Design
- 🔑 Primary & Foreign Key Constraints

---

## 🛠 Technologies Used

- Microsoft SQL Server 2022
- SQL Server Management Studio (SSMS)
- T-SQL

---

## 📂 Database Structure

The database includes tables for:

- Employees
- Departments
- Positions
- Salaries
- Employee Records
- Organizational Data

---

## 📖 Concepts Applied

- Relational Database Design
- Database Normalization
- Primary Keys
- Foreign Keys
- One-to-Many Relationships
- Data Integrity
- SQL Queries
- Database Backup & Restore

---

## 📁 Project Files

- `EmployeesDB.sql` – Complete SQL script for creating the database.
- `EmployeesDB.bak` – SQL Server backup file.

---

## 🚀 How to Run

1. Open SQL Server Management Studio (SSMS).
2. Restore the database using `EmployeesDB.bak` **or** execute `EmployeesDB.sql`.
3. Run SQL queries and explore the database.
